# Mansi & Iskand — Wedding Invitation Website

A mobile-first, animated wedding invitation website built with React and Vite.

## Run locally

1. Install Node.js (18+ recommended).
2. Extract this folder.
3. In the project folder, run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
npm run preview
```

Deploy the generated `dist` folder to Vercel, Netlify, or another static hosting provider.

## Personalise before publishing

- Confirm the venue address and date in `src/App.jsx`.
- Add the exact wedding timings and any additional ceremony details if needed.
- The RSVP button currently opens WhatsApp with a pre-filled message; guests choose the family contact to send it to.
- The music toggle is a visual placeholder. Add a licensed/owned audio file and playback logic if you want background music.
- Replace the illustrated couple emblem with approved couple artwork or photos if desired.

## Tech

React, Vite, CSS animations, Lucide icons.
